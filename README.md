# 경찰청 통합 인트라넷 (RP)

경찰 역할극 커뮤니티를 위한 한국어 인트라넷 UI입니다. 인사·조직, 출퇴근, 사건 관리, 공지·공문, 감사 로그 화면을 제공합니다.

## 데모 사용
- 웹사이트는 정적 HTML로 제공되며, 입력한 데이터는 현재 브라우저의 localStorage에 저장됩니다.
- 브라우저/기기 간 동기화, 실제 사용자 인증, 중앙 데이터베이스 저장은 아직 연결되어 있지 않습니다.
- 샘플 인원과 사건은 가상 RP 데이터입니다. 실제 개인정보나 현실 사건 정보를 입력하지 마세요.

## 배포
GitHub Actions가 `site/` 디렉터리를 GitHub Pages로 배포합니다. 저장소의 **Settings → Pages**에서 Source가 **GitHub Actions**로 설정되어 있어야 합니다.

## 다음 단계: 실제 운영용 연결
실제 운영에 사용하려면 Supabase 데이터베이스 및 Discord OAuth 로그인 연결, 역할별 서버 측 권한 검증, Row Level Security 정책 검토가 필요합니다. 브라우저 코드만으로 관리자 권한을 보호할 수 없습니다.
